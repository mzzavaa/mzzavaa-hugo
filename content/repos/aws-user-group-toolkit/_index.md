The AWS User Group Toolkit collects the practical bits behind running a meetup: a header image generator, a PNG to SVG converter, badge and name tag templates, a welcome message, a small website, and the knowledge base and Sessionize connector for OTTO, our [event-planning agent idea](/posts/building-otto/). The templates describe it as a grassroots community project started by the AWS Meetup Vienna, not affiliated with or endorsed by AWS. Most repos were written by Philipp Bergsmann. My own share is the OTTO knowledge base, the first version of the Austria slide templates, and a few smaller commits. The org also holds two forks of a GameDay event repo, which are test copies only.

{{< junior >}}This org feels like a shared toolbox in a meetup back room. Philipp built most of the tools, often in one afternoon with a container and a GitHub Actions workflow attached, and I reach in to add a piece when a meetup needs it. The commit messages still mention the old org name, aws-community-toolkit, so it has moved house at least once.{{< /junior >}}

{{< senior >}}Ten repos, none of them active in the last 60 days. Three small tools look finished, five are quiet, one has only a single initial commit and one is empty. Several READMEs are a single heading, two repos have no licence, and some docs still point at the old org name. The honest summary: a useful toolbox that would benefit from one tidy-up day.{{< /senior >}}
