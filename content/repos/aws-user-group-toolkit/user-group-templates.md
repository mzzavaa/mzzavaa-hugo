A small set of templates for user group leaders: four role badges (Leader, Speaker, Host, First-Timer) as a printable sticker PDF, a name tag label template, and a welcome message for new members on the meetup platform. Philipp Bergsmann made all of it in one day in March 2024.

{{< junior >}}
This is the least technical repo in the org and maybe the most useful on a meetup night. What I noticed:

- The badge README explains why each role gets a sticker. The First-Timer badge is an invitation for regulars to say hello, which I love.
- The welcome message has clear `###ADD YOUR MEETUP LOCATION###` style placeholders, so you can copy it in two minutes.
- Every README ends with the same note: a grassroots community project from the AWS Meetup Vienna, not affiliated with AWS.
{{< /junior >}}

{{< senior >}}
Thirteen commits on 8 March 2024 and nothing after. For a template pack that is finished, and that is fine. It has an index README linking each part, an MIT licence and a disclaimer in every file. A stranger would need the matching label sheets, and the README names the exact Avery product, which helps. The name tag template is a `.lbx` file for one label printer brand, so groups without that printer have nothing to start from. A PDF version would widen it.
{{< /senior >}}

**Learned:** A sticker with "First-Timer" on it does more for a meetup than most code.
