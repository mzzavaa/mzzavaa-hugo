The organisation behind the volunteer-run AWS meetups in Vienna and Linz. It holds the source of awscommunity.at, the home of the AWS community in Austria, and a set of small repos that turn one Meetup event link into a whole meetup evening: the room screen, the filled-in slide deck and a page per meetup on the website. I have organised the AWS User Group Vienna for more than seven years, and I wrote nearly everything here.

{{< junior >}}Building here feels like tidying a workshop I have used for years. The website started in March, and on 19 October most of the meetup tools got their first commits on the same day, each one its own repo with the same table pointing at the others. One `make start` in the workspace runs the evening.{{< /junior >}}

{{< senior >}}Nine repos. Seven had commits today, one is the first attempt from April that the new tools replaced, and one is empty. Eight have a README; only the old first attempt has a licence, which matters when the profile says the tools are free to reuse. A burst like this needs a tidy-up pass before strangers find it, and after that it is fine for the repos to go quiet between meetups.{{< /senior >}}
