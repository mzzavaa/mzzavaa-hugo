The profile page a visitor sees first on the aws-user-groups-austria organisation. One README that lists the groups in Vienna, Linz and St. Pölten, says how to speak at or host a meetup, and has a table of the repositories with one line each.

{{< junior >}}
- One commit, today. I wrote it after the other repos existed, so the table could point at real things.
- The groups are a table with their icons pulled from awscommunity.at, so the logos live in one place.
- "Get involved" has three entry points: speak, host, or read the meetup pages.
- It ends with a line that the user groups are run by volunteers and are not affiliated with Amazon Web Services. I wanted that visible, not buried.
{{< /junior >}}

{{< senior >}}
One commit on 19 October 2026. This is the page that decides whether a stranger clicks further, and it does its job: short, with a clear "start here" pointer to `meetup-workspace`. It says the tools are free to reuse, but the repos it lists carry no licence, so a careful reader cannot actually reuse them yet. It also gives a member count, which goes stale without anyone noticing. A profile is fine to leave alone for months; those two lines need a check now and then.
{{< /senior >}}

**Learned:** If the profile says "free to reuse", the repos need a licence file to back it.
