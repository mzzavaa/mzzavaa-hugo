The landing site for [sisy.social](https://sisy.social). SISY helps women become visible as experts, speakers and leaders, and helps organisers find voices beyond their usual networks. The site explains both halves: the SISY platform and the open source Sisy framework.

{{< junior >}}
- I built the first version in March 2026 with Claude, as a pull request from a branch, then merged it myself.
- Hugo, one custom CSS file, no framework. The design became the SISY design system that my other SISY pages now follow.
- Four pages: home, platform, framework, about. Enough to explain the idea without pretending the product is finished.
- In April I came back for the logo, the Discord link and a tools page.
{{< /junior >}}

22 commits between 22 March and 25 April 2026, quiet since. For a landing page that is fine: it says what SISY is and where to join. The README is clear about pages and stack. When the platform moves, this page should move with it.
