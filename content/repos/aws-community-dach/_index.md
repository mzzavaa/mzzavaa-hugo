The two repos here form the AWS Community DACH event system: a Next.js frontend for participant registration and check-in, and a serverless AWS CDK backend behind it. Both are Apache 2.0 licensed. I chair the AWS Community DACH nonprofit, but I did not write this code. It was built by community volunteers, mainly Eduard Schwarzkopf, Thorsten Hoeger, timros1412 and makellner.

{{< junior >}}Reading this felt like walking into someone else's workshop. Two repos, a clear split between web app and API, and a commit history full of small, practical fixes made right before events. I learned a lot just from how they wired check-in into the flow.{{< /junior >}}

{{< senior >}}Both repos have been quiet since September 2024. For an event system that is not alarming on its own, because the work is seasonal. The backend README is still the projen placeholder, and neither repo says how a new volunteer would pick it up for the next event. That handover note is what's missing.{{< /senior >}}
